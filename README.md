# BudgetBuddy (iOS SwiftUI)

Native iOS budgeting app scaffold with:
- Monthly budget categories
- Transaction tracking
- Dashboard totals (budget, spent, remaining)
- Local persistence via `UserDefaults`

## Requirements

- Xcode 15+
- XcodeGen (`brew install xcodegen`)

## Run

```bash
cd /Users/warl0ck/Code/BudgetBuddy
xcodegen generate
open BudgetBuddy.xcodeproj
```
